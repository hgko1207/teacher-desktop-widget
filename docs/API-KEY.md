# API 키 발급 가이드 (API-KEY.md)

이 앱이 쓰는 외부 API 키 발급·입력 방법입니다.

## 어떤 키가 필요한가?

| 위젯 | 키 | 필수? |
|------|-----|------|
| 날씨 | 없음 (wttr.in) | — |
| 시간표 | 없음 (컴시간) | — |
| 급식 / 학사일정 | NEIS | ❌ 선택 (키 없이도 동작, 안정성 원하면 발급) |
| **미세먼지** | **에어코리아 (data.go.kr)** | ⚠️ 미세먼지를 보려면 필요 |

> 미세먼지를 안 쓰면 키는 하나도 필요 없습니다. 미세먼지를 보고 싶을 때만 에어코리아 키를 발급하세요.

---

## 1. 에어코리아(미세먼지) 키 — data.go.kr

### 발급 절차
1. **공공데이터포털** 접속 → https://www.data.go.kr → 회원가입 / 로그인
2. 검색창에 **`한국환경공단 에어코리아 대기오염정보`** 검색
3. **오픈 API** 탭에서 **"한국환경공단_에어코리아_대기오염정보"** 클릭
4. 상세 페이지 우측 **[활용신청]** 버튼 클릭
5. 활용목적 입력(예: `개인 학습용 데스크탑 위젯`) → 약관 동의 → **신청**
6. 대기오염정보는 보통 **즉시 자동 승인**됩니다.
   - **마이페이지 → 데이터활용 → Open API → 인증키 확인**에서 키를 확인

### ⚠️ 중요 — "Decoding 키"를 복사하세요
발급되면 인증키가 **두 가지** 보입니다:
- 일반 인증키 **(Encoding)** ← URL 인코딩된 버전
- 일반 인증키 **(Decoding)** ← 원본 ✅ **이걸 쓰세요**

> 이 앱은 코드에서 키를 다시 URL 인코딩(`encodeURIComponent`)합니다 ([index.ts:656](src/main/index.ts#L656)).
> 그래서 **Decoding 키(원본)**를 넣어야 정상 동작합니다.
> Encoding 키를 넣으면 이중 인코딩되어 **인증 실패(데이터 안 옴)**가 납니다. 가장 흔한 실수예요.

### ⏱️ 발급 직후 1시간 정도는 안 될 수 있음
data.go.kr 키는 활용신청 직후 트래픽 반영에 시간이 걸립니다. 키를 넣었는데 미세먼지가
안 뜨면 **1시간쯤 뒤에 다시** 확인해 보세요 (키가 틀린 게 아닐 수 있음).

### 참고
- 개발계정 일일 호출 한도는 보통 넉넉(약 10,000건/일)해서 개인 사용엔 문제없습니다.
- 지역 설정은 **시도 단위 이름**이어야 합니다(서울/부산/경기/강원/충북/충남/전북/전남/
  경북/경남/제주/세종 등). 앱 설정의 지역이 시도명과 맞아야 데이터가 옵니다.

## 2. NEIS(급식·학사일정) 키 — 선택사항

키 없이도 급식·학사일정이 동작하므로 **보통은 발급할 필요가 없습니다.** 다량 호출 시
제한이 걱정될 때만 발급하세요.

1. **나이스 교육정보 개방 포털** 접속 → https://open.neis.go.kr → 회원가입 / 로그인
2. **마이페이지 → 인증키 관리 → 인증키 신청**
3. 발급된 인증키를 복사

---

## 3. 앱에 키 입력하는 법

1. 앱 실행 → **설정**(톱니바퀴) 열기
2. 입력칸 위치 ([SettingsModal.tsx](src/renderer/src/components/widgets/SettingsModal.tsx)):
   - **NEIS API 키** 칸 — 비워둬도 됨
   - **에어코리아 API 키 (미세먼지, 선택사항)** 칸 — 여기에 **Decoding 키** 붙여넣기
3. 입력하면 자동 저장(로컬 `electron-store`)되고, 잠시 후 미세먼지가 표시됩니다.

> 키는 코드나 깃에 저장되지 않고, 사용하는 PC에만 로컬로 저장됩니다.
